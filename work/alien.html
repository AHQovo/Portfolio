在废土世界里搭建三类外星生物、远程战斗与任务体系，并用 C# 把核心功能做成可运行的原型。

01 / OVERVIEW

项目概览

一款以「外星人入侵废土世界」为核心设定的科幻动作冒险游戏。

作品融合沉浸式剧情、多样化战斗与自由探索体验，支持玩家操控机甲角色与不同类型外星生物对抗，守护地球家园。项目同时承担策划与程序工作，从世界架构、敌人设定到战斗功能和 HUD 实现均由本人参与完成。

WORLD

废土世界构建

城市废墟、外星基地与科研基地构成多元场景，为探索、战斗和叙事提供不同的空间语气。

COMBAT

远程战斗核心

围绕远程射击、集束弹药技能释放与闪避走位设计战斗操作，保持键盘 + 鼠标的简洁响应。

QUEST

任务推进闭环

搭建主线剧情框架与任务体系，明确任务触发逻辑、进度反馈及奖励机制。

02 / MY ROLE

我的工作 策划 + 程序

策划 / DESIGN

  1. 01

    负责游戏核心架构设计，构建科幻废土风格世界，涵盖城市废墟、外星基地、科研基地等多元场景；设定机械变异类、辐射异化类、生物进化类三类外星生物的形态、攻击模式及弱点。

  2. 02

    搭建主线剧情框架与任务体系，明确任务触发逻辑、进度反馈及奖励机制。

  3. 03

    主导战斗系统策划，设计远程射击、集束弹药技能释放、闪避走位等核心玩法；优化操作逻辑，确保键盘 + 鼠标的操控方式简洁易上手且响应迅速；结合虚拟现实专业知识融入场景交互细节，提升沉浸感。

程序 / DEVELOPMENT

  1. 01

    基于 C# 的 .NET Framework 环境完成核心功能编码，实现角色移动、攻击判定、技能特效触发、血条与伤害显示等功能模块。

  2. 02

    适配不同软硬件环境，确保游戏在安装与未安装 .NET Framework 的电脑上均能正常运行。

03 / DESIGN NOTES

设计重点

这个项目让我同时从「设定是否成立」和「功能是否能跑」两端检查设计：敌人分类需要对应不同的战斗行为，场景需要服务探索与战斗节奏，而所有操作最终都要落到可验证的输入、判定和反馈上。

  • 敌人分类：三类外星生物分别承担不同的形态、攻击模式与弱点设定，构成战斗内容的差异来源。

  • 战斗操作：远程射击、集束弹药与闪避走位形成攻防节奏，操作路径保持直接、快速反馈。

  • 技术落地：用 C# 实现移动、攻击判定、技能特效、血条与伤害显示，并处理 .NET Framework 环境兼容。
