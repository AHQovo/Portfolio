01 / OVERVIEW

项目概览

一款以「抛竿—咬钩—收鱼—养成」为完整闭环的休闲养成游戏。

玩家选择关卡后蓄力抛竿，等待鱼类咬钩，并通过节奏判定（QTE）完成收鱼；获取奖励后用于装备升级与鱼类收集。作品以 2D 治愈系 Q 版美术风格呈现，并划分不同水层生态以支撑长线收集目标。

02 / GAME DESIGN

策划设计

  1. 01

    核心玩法搭建。主导设计「选择关卡 → 蓄力抛竿 → 等待咬钩 → QTE 收鱼 → 奖励获取 → 养成提升」的闭环玩法，融合节奏判定绿条控制逻辑，设计动态 QTE 模式，强化操作趣味性。

  2. 02

    关卡与场景规划。设计主题场景及线性解锁小关卡，明确各关卡通关条件；划分表层、中层、深层、海底四大水层，绑定蓄力时间与水层深度关系，并配置专属鱼类生态与视觉效果。

  3. 03

    系统体系设计。搭建聚焦鱼竿、浮标装备升级与技能解锁的养成体系，不设角色等级成长；设计「喵币」单一经济系统，规划钓鱼产出、成就奖励、每日任务等产出渠道，以及商城兑换、家园升级等消耗场景，并配套防通胀机制。

  4. 04

    收集与激励设计。构建鱼类图鉴系统，区分普通、稀有、传说三类鱼种标签与收集成就；设计 11 项成就徽章及「喵币」激励体系，关联鱼类收集、关卡通关、操作熟练度等维度，提升玩家留存率。

  5. 05

    美术与音效规范。确定 2D 治愈系 Q 版美术风格，制定主色调、功能模块色及场景分层色规范；规划场景专属背景音乐与操作音效，包括蓄力声、咬钩提示音等，强化沉浸体验。

03 / SYSTEMS

04 / DEVELOPMENT

程序开发 Unity 2D

  1. 01

    核心功能实现。完成蓄力抛竿物理效果、多水层视觉分层呈现、动态 QTE 交互逻辑、鱼类咬钩判定等模块开发。

  2. 02

    数据与系统开发。搭建鱼类图鉴数据库、装备养成数值体系、经济循环计算逻辑；实现成就解锁、奖励发放、存档读档等功能，保障数据稳定性。

  3. 03

    交互体验调优。迭代 QTE 手感参数（绿条大小、鱼类移动速度），动态调整难度曲线；为新手配置简化操作引导，并实现动态色彩反馈与音效同步。

05 / OUTCOME

项目成果

  • 玩法落地：实现动态 QTE 收鱼与水层探索玩法，核心循环流畅，不同鱼种 QTE 模式差异化明显，操作门槛低且具策略性。

  • 内容完善：完成主题场景、关卡及三类鱼类图鉴搭建，收录普通、稀有、传说级鱼种。

  • 激励有效：成就徽章与「喵币」体系有效提升玩家活跃度，关卡通关率与鱼类收集率达成预期目标，核心用户留存表现良好。
